# Installing Ukeplan (no terminal needed)
 
Download the file for your computer from the **Releases** page, unzip it, and open Ukeplan.
 
| Computer | Download |
|---|---|
| Windows | `Ukeplan-Windows.zip` |
| Mac with Apple chip (M1 or newer) | `Ukeplan-Mac-AppleSilicon.zip` |
| Older Intel Mac | `Ukeplan-Mac-Intel.zip` |
| Linux | `Ukeplan-Linux.tar.gz` |
 

## First launch

 
**Windows:** unzip the folder (right-click ▸ Extract All), open `Ukeplan.exe`. If "Windows protected your PC"
appears, click **More info**, then **Run anyway**.
 
**Mac:** unzip, drag **Ukeplan** to Applications. The first time, **right-click it ▸ Open ▸ Open**.
If that is blocked: System Settings ▸ Privacy & Security, scroll down, click **Open Anyway**.
 
**Linux:** extract, run `Ukeplan/Ukeplan`.
